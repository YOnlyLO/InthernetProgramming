# Стек технологий проекта

Проект представляет собой веб-приложение с клиент-серверной архитектурой. Разработка разделена на клиентскую и серверную части, взаимодействующие между собой посредством REST API.

## Frontend

Клиентская часть приложения разрабатывается с использованием Angular — фреймворка для создания динамических одностраничных веб-приложений (SPA).

### Основные технологии Frontend:

* **Angular** — основной фреймворк клиентской части приложения. Используется для построения компонентов, страниц, маршрутизации и организации структуры приложения.
* **TypeScript** — основной язык разработки. Используется для написания компонентов, сервисов, моделей данных и бизнес-логики клиентской части.
* **HTML5** — используется для формирования структуры и содержимого пользовательского интерфейса.
* **SCSS** — используется для стилизации компонентов, создания адаптивного интерфейса и организации CSS-кода.
* **Angular Router** — отвечает за маршрутизацию между страницами и разделами приложения без необходимости полной перезагрузки страницы.
* **Angular HttpClient** — используется для отправки HTTP-запросов к серверной части приложения и получения данных через REST API.
* **RxJS** — применяется для работы с асинхронными операциями, HTTP-запросами и потоками данных.
* **Angular Forms** — используется для создания и обработки пользовательских форм, а также выполнения клиентской валидации данных.
* **JWT (JSON Web Token)** — используется для организации авторизации и передачи информации о сессии пользователя между клиентской и серверной частями.

## Backend

Серверная часть приложения разрабатывается с использованием C# и платформы ASP.NET Core.

### Основные технологии Backend:

Современный, высокопроизводительный и надежный стек для **Enterprise-разработки** и создания серверной части (Backend) веб-приложений.

*   **C#** — мощный объектно-ориентированный язык программирования со строгой типизацией и высокой скоростью работы.
*   **ASP.NET Core** — один из самых быстрых в мире веб-фреймворков для создания масштабируемых RESTful API и микросервисов.
*   **EF Core** — передовая ORM-система для удобного управления базой данных через код C# без ручного написания SQL.
*   **PostgreSQL** — надежная реляционная база данных с открытым исходным кодом, поддерживающая сложные запросы и работу с JSONB.

### Функциональные модули системы

Для удобства разработки система разделена на логические модули. Каждый модуль включает в себя UI-компоненты на стороне Frontend и соответствующие контроллеры/сервисы на стороне Backend.

*   **Модуль аутентификации и авторизации (Auth Module):**
    *   *Frontend:* Экраны входа, регистрации и восстановления доступа. Angular Guards для защиты страниц от неавторизованных пользователей.
    *   *Backend:* Сервис генерации и валидации JWT. Контроллер аутентификации, хэширование паролей, а также разграничение прав на основе ролей (Role-Based Access Control — RBAC).
*   **Модуль профиля пользователя (User Profile Module):**
    *   *Frontend:* Личный кабинет, формы редактирования персональных данных, загрузка аватара, смена пароля.
    *   *Backend:* Контроллер управления данными пользователей, валидация входящих DTO (Data Transfer Objects), обновление записей в PostgreSQL через EF Core.
*   **Основной бизнес-модуль (Core Business Module):**
    *   *Frontend:* Рабочие панели (Dashboards), списки, формы ввода и таблицы для отображения целевых данных учебного проекта.
    *   *Backend:* Сервисный слой, реализующий базовую логику приложения. Обработка запросов на добавление, изменение и получение информации, взаимодействие с базой данных через EF Core.
*   **Модуль административного управления (Admin Module):**
    *   *Frontend:* Панель администратора с расширенными правами доступа. Просмотр списков пользователей, управление их ролями или блокировка.
    *   *Backend:* Контроллеры, защищенные атрибутом доступа `[Authorize(Roles = "Admin")]` для выполнения административных CRUD-операций.

### Главные преимущества
1. **Высокая производительность** — легко справляется с высокими нагрузками (Highload).
2. **Кроссплатформенность** — полноценно работает на Linux, Windows и отлично разворачивается в Docker-контейнерах.
3. **Безопасность и стабильность** — строгая типизация и встроенные механизмы защиты от SQL-инъекций и XSS.
4. **Быстрая разработка** — зрелая экосистема позволяет оперативно собирать и масштабировать бизнес-логику любой сложности.
