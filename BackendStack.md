# Стэк технологий на Backend'е сервиса
## Взаимодействие по сети
### ASP.NET Core
Для реализации Api приложения используется платформа ASP.NET
## Данные
### БД
В качестве реляционной базы данных используется PostgreSQL.
### Работа с БД
Для работы с БД используется ORM Entity Framework с подходом разработки code-first.
## Аутентификация
### JWT
Для реализации аутентификации используется JWT токен совметсно с cookie.
## Авторизация
### Role-base authorization
В качетсве реализации авторизации используется подход доступа к ресурсу в зависимости от роли пользователя.
