## Краткое описание проекта
**FRIENDWISH** — веб-сервис для создания и просмотра списков желаний, предназначенный для упрощения выбора подарков для друзей и близких.

Зарегистрированные пользователи могут создавать собственные списки желаний, добавлять в них товары с названием, описанием, ценой и ссылкой, а также редактировать и удалять добавленные желания. Пользователи могут находить друг друга, отправлять и принимать заявки в друзья и просматривать списки желаний своих друзей. Доступ к списку желаний другого пользователя предоставляется только при наличии соответствующего отношения «друзья».

Сервис предусматривает регистрацию и авторизацию пользователей, управление профилем и разграничение прав доступа. Авторизация выполняется с использованием JWT, а взаимодействие клиентской и серверной частей осуществляется через REST API. Данные системы хранятся в реляционной базе данных PostgreSQL.

Для пользователей с ролью администратора предусмотрена административная панель, позволяющая управлять учетными записями пользователей, изменять их роли, а также блокировать и разблокировать учетные записи.

Таким образом, FRIENDWISH объединяет список желаний, социальное взаимодействие между пользователями и базовые административные функции в едином веб-сервисе.
