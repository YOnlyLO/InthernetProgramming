# FRIENDWISH. Сервис для удобного отслеживания подарков для близких

## Краткое описание проекта

**FRIENDWISH** — веб-сервис для создания и просмотра списков желаний, который упрощает выбор подарков для друзей и близких.

Зарегистрированные пользователи создают собственные списки желаний (название, описание, цена, ссылка на товар), находят друг друга, добавляют в друзья и просматривают списки желаний друзей. Администратор управляет учетными записями: меняет роли, блокирует и разблокирует пользователей.

Подробное описание требований — в [техническом задании](TechTask.md).

## Стек технологий

- **Backend:** C#, ASP.NET Core Web API, Entity Framework Core, PostgreSQL, JWT;
- **Frontend:** Angular, TypeScript, HTML5, SCSS, Angular Router и Guards, HttpClient, RxJS, Angular Forms;
- **Тестирование:** xUnit, WebApplicationFactory, модульные тесты Angular, end-to-end тесты;
- **Инструменты:** Git, GitHub (Issues, Milestones, Pull requests), Swagger, Postman.

## Планируемые задачи по спринтам

Каждый спринт оформляется отдельным Milestone, каждая задача — отдельным Issue. Подробности — в разделе 14 [технического задания](TechTask.md).

### Спринт 1. Постановка задачи

1. Оформление README.md и технического задания.
2. Базовый проект с выбранным стеком и инструкцией по запуску.

### Спринт 2. Backend

1. Модель данных (`User`, `Wish`, `Friendship`), подключение PostgreSQL, миграции EF Core.
2. Регистрация и авторизация: валидация, хэширование паролей, выдача JWT.
3. Профиль пользователя: просмотр, редактирование, смена пароля.
4. Список желаний: CRUD для своих желаний, просмотр списка друга.
5. Друзья и поиск пользователей: заявки, принятие, отклонение, удаление.
6. Административное API: роли, блокировка и разблокировка.
7. Документация API в Swagger, описание запуска backend.
8. Подготовка frontend к интеграции: макеты страниц, модели данных, сервисы API.

### Спринт 3. Frontend

1. Каркас приложения: маршрутизация, общий макет, HTTP-interceptor для JWT.
2. Регистрация и вход, защита маршрутов через `AuthGuard` и `AdminGuard`.
3. Страница профиля.
4. Мой список желаний: просмотр, добавление, редактирование, удаление.
5. Друзья и поиск пользователей.
6. Просмотр списка желаний друга.
7. Административная панель.
8. Единый стиль и адаптивная верстка.
9. Интеграция backend с клиентом: CORS, аватары, доработка API.

### Спринт 4. Тестирование

1. Модульные тесты backend (xUnit).
2. Интеграционные тесты API.
3. Модульные тесты frontend.
4. End-to-end тесты основных сценариев.
5. Исправление ошибок и итоговая документация.
