# Wishlist. Сервис для удобного отслеживания подарков для близких.
## Краткое описание проекта
Сервис позволяет зарегистрированным пользователям отслеживать добавленные в список желания товары пользователей, добавленных в "Друзья". Список желания представляет собой строки, содержащие наименование, краткое описание, ссылку на товара и цену.
