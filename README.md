# WishList. Сервис для удобного отслеживания подарков для близких.
## Функционал сервиса.
### Краткое описание
Приложение позволяет публиковать в сервисе свой список желаний, который будет отображаться добавленным в "Друзья" пользователям.
Сам предмет из списка содержит в себе название, краткое описание и ссылку на товар (маркетплейс или другой ресурс).
### Администрирование
Пользователь может свободно изменять свой список желаемого.
Администратор сервиса имеет доступ к спискам всех пользователей сервиса и может вносить изменения в них в случае необходимости.
